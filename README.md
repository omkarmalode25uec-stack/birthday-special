# 🌸 A Little Birthday Surprise For Renuka 🎀

An interactive digital birthday storybook created with love by **Omkar** for **Renuka**.

---

## ✨ Features Included

1. **💌 Opening Screen**: An illustrated pastel envelope with heart wax seal, floral petals, and realistic opening animations.
2. **💗 Personal Birthday Letter**: A textured stationery letter with the exact personal letter from Omkar to Renuka, handwritten signature, and corner blooming flowers.
3. **📸 Memory Lane Scrapbook**: Continuous automated slideshow with Polaroid frames, washi tapes, crossfades, zoom effects, and full-screen lightbox.
4. **🎂 Cake Time**: 3-tier pastel birthday cake with candle blowing, smoke drift, cake-cutting animation, and a party-hat teddy bear mascot.
5. **⭐ Make a Wish**: Dreamy golden glowing ripple effect, floating stars, hearts, and warm background glow.
6. **🌙 The Magical Lighting Room**: A cinematic dark room where pulling the light bulb cord illuminates the room with fairy lights, balloons, and "HAPPY BIRTHDAY RENUKA" banners.
7. **🎁 Nine Mystery Gift Boxes**: Interactive 3x3 box game with randomized winning placement. Winning gift: **One Cold Coffee + One Onion Uttapam (Your treat is on me! ❤️)** with consolation prizes for other boxes.
8. **🎀 Final Celebration**: Grand birthday finale with party poppers, teddy bear, cake, and a replay button.
9. **🌸 Global Blossom & Confetti System**: Canvas-based falling cherry blossom petals, blooming corner flowers on section load, and interactive petal bursts.
10. **🎵 Floating Music Player**: Non-stop background music across all sections. Includes Web Audio API music-box fallback if `birthday.mp3` is not present yet!
